# Ozon Review Parser

## 📌 Описание
**Ozon Review Parser** — это инструмент для автоматизированного сбора отзывов о товарах с маркетплейса Озон.
Парсер открывает карточки товаров по артикулу, переходит в раздел отзывов, прокручивает страницу, собирает все доступные отзывы (по нескольким страницам) и сохраняет их в Excel.

## 🚀 Установка
1. **Клонируйте репозиторий (либо скачайте архив с GitHub):**
   ```bash
   git clone <URL_этого_репозитория>
   cd ozon_review_parser
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## 📌 Использование
1. Запустите скрипт `main.py`:
   ```bash
   python main.py
   ```
2. Введите артикулы товаров через запятую (например, `2266863027, 1969291726`).
3. Скрипт для каждого товара:
   - откроет карточку;
   - перейдёт в раздел отзывов;
   - проскроллит страницу до конца, чтобы подгрузить все отзывы;
   - пройдёт по страницам отзывов (до разумного лимита).
4. После завершения работы результат будет сохранён в папке `results/` в файл формата:
   ```text
   ozon_reviews_<первые_три_артикула>_<дата_и_время>.xlsx
   ```

## ⚠ Примечания
- Для работы парсера требуется установленный **Google Chrome**.
- При первом запуске автоматически будет загружен/обновлён **ChromeDriver** (через `webdriver-manager`).
- Загрузка отзывов может занять некоторое время (несколько минут), так как сайт Ozon подгружает данные постепенно и может ограничивать скорость запросов.
